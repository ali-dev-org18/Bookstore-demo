# 📚 Online Bookstore Platform (Onlayn Kitob Do'koni)

Kitoblarni onlayn ko'rish, qidirish va xarid qilish uchun mo'ljallangan to'liq funksional (full-stack) veb-ilova. Loyiha kengaytiriluvchan arxitektura va foydalanuvchilar uchun qulay interfeysga asoslangan.

---

## ✨ Asosiy Funksiyalar

* **Kitoblar Katalogi va Filtrlash:** Kitoblarni kategoriya, muallif, narx oralig'i va nashr etilgan yili bo'yicha saralash.
* **Kengaytirilgan Qidiruv:** Kitob nomi, muallifi yoki ISBN kodi orqali tezkor qidiruv tizimi.
* **Autentifikatsiya va Profil:** Ro'yxatdan o'tish, tizimga kirish va shaxsiy profilni boshqarish.
* **Savat va Sevimlilar (Wishlist):** Kitoblarni savatga qo'shish, sonini o'zgartirish yoki keyinroq xarid qilish uchun saqlab qo'yish.
* **Buyurtmalarni Boshqarish:** Xaridni rasmiylashtirish, buyurtmalar tarixi va holatini kuzatib borish.
* **Admin Panel:** Kitoblar, mualliflar, kategoriyalar va mijozlar buyurtmalarini to'liq boshqarish (CRUD).
* **Izohlar va Reyting:** Ro'yxatdan o'tgan foydalanuvchilar kitoblarga baho berishi va fikr qoldirishi mumkin.

---

## 🛠️ Ishlatilgan Texnologiyalar (Tech Stack)

* **Backend:** Python, Django (yoki Django REST Framework)
* **Frontend:** HTML5, CSS3, JavaScript (Bootstrap / Tailwind CSS)
* **Ma'lumotlar bazasi:** PostgreSQL / SQLite
* **Versiya nazorati:** Git & GitHub
